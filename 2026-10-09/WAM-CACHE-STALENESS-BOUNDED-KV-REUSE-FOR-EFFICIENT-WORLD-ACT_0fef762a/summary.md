# 论文速读：WAM-CACHE: STALENESS-BOUNDED KV REUSE FOR EFFICIENT WORLD ACTION MODELS

## 一句话总结
本文提出 WAM-Cache，一种训练免费的键值（KV）缓存复用框架，通过联合动作专家注意力与视觉潜在惊喜选择稀疏刷新集，并结合严格年龄上限抑制误差累积，在保持世界动作模型（WAM）任务成功率几乎不降的前提下，显著削减视频 DiT 预填充的计算开销。

## 研究问题与动机
- **核心瓶颈**：在闭环控制的 WAM 中，视频 DiT 预填充（将观测编码为层级 KV 对）占据每个控制块（chunk）绝大部分计算量；随着动作专家去噪步数减少（如从 10 步降至 2 步），该部分占比进一步上升至 83.5%。
- **现有方法局限**：重训练方法（蒸馏、压缩）成本高；训练免费方法（如 DeepCache、VLA-Cache）无法稀疏化视频 DiT 预填充，仍须全量稠密计算。
- **刷新策略失效**：直觉上刷新“视觉漂移”的 token 会导致成功率大幅下降（即使在 oracle 知晓真实 KV 漂移时仍低于稠密基线 25 个百分点），因为下游动作准确率取决于动作专家关注的位置，而非视觉变化本身。
- **误差累积风险**：基于排名的选择可能使未选中的 token 被无限期复用，导致缓存误差不断累积，无法接近稠密策略性能。

## 核心贡献（创新点）
- **首次针对视频 DiT 预填充的训练免费 KV 缓存框架**：WAM-Cache 保留层级 KV 表示跨块复用，仅重新计算稀疏刷新集的 token，无需任何重训练。
- **发现刷新应遵循策略注意力而非视觉漂移**：通过消融证明，仅依赖变化信号（像素差、潜在惊喜、oracle KV 漂移）的性能天花板远低于稠密模型；而动作专家交叉注意力能恢复大部分性能缺口。
- **设计三信号联合的稀疏刷新集选择机制**：融合潜在惊喜（特征漂移）、动作条件注意力（下游敏感度）与年龄上限（强制周期刷新），三者互补且开销极低。
- **提供严格的全局误差界**：年龄上限确保每个 KV 对最多连续复用 G 个块，从根本上抑制误差累积，使性能差距缩小至 1.8 个百分点。
- **在多项基准上实现显著加速且精度损失小**：在 RoboTwin 2.0、LIBERO 及真实机器人实验中，削减 32–42% 预填充 FLOPs，同时保持接近稠密策略的成功率。

## 方法详解
- **缓存状态维护**：每个视觉 token 维护缓存 KV 对、参考嵌入、年龄计数器及上一块的动作专家注意力质量。
- **稀疏刷新集构建**：每块 t 的刷新集 R_t 由三部分取并集：潜在惊喜集 S_t（基于当前嵌入与参考嵌入的距离）、动作注意力集 P_t（基于上一块动作专家的平均交叉注意力）、年龄集 A_t（年龄计数器达到上限 G 的 token）。
- **混合缓存执行**：视频 DiT 仅对刷新集 token 执行完整前向传播，更新层级 KV；未选中 token 保留旧 KV。动作专家在混合缓存上运行去噪， queries 仅由刷新 token 形成并 attends 全部 KV。
- **潜在惊喜度量**：计算归一化 L2 距离 s_t[i] = ||z_t[i] - z_{τ_i}[i]||_2 / (0.5*(||z_t[i]||_2 + ||z_{τ_i}[i]||_2) + ε)，取 TopK 作为刷新候选。
- **动作条件选择**：聚合动作专家跨层、跨 query 的交叉注意力 p_t[i]，取 TopK 得到 P_t，利用已有注意力图零额外开销。
- **年龄上限机制**：设置固定阈值 G，当 g_i ≥ G 时强制刷新；更新规则为 g_i ← 0（若被刷新）或 g_i ← g_i+1。该机制以极低开销（仅标量比较）保证泛化性。
- **计算节省分析**：设刷新比例 ρ_t = |R_t|/S_v，每模块 FLOPs 从 C_dense 降至 ρ_t·C_dense，节省比例为 1-ρ_t。理论证明时间平均刷新比例 ρ̄ ≤ b_s + b_a + 1/(G+1)。

## 实验与结果
- **仿真基准**：RoboTwin 2.0（50 个双臂任务，干净/随机场景）和 LIBERO（4 个子集共 40 个单臂任务）。
- **评估基线**：FastV、ToMe、Eventful Transformer、VLA-Cache，均在相同预填充 FLOPs 预算下对比。
- **RoboTwin 2.0 结果**：默认预算下削减 41.6% FLOPs，成功率下降 1.8 个百分点（88.36% vs 90.16%）；更大预算下削减 28.2% FLOPs，仅降 0.1 个百分点。最强基线 VLA-Cache 在相同预算下损失至少 4.0 个百分点。
- **LIBERO 结果**：削减 32.3% FLOPs，成功率平均 95.85% vs 稠密 96.50%；更大预算削减 26.1% FLOPs，平均成功率与稠密持平。
- **真实机器人实验**：在 AIRBOT Play 机械臂上进行“胡萝卜入碗”和“堆叠立方体”任务，削减 40.2% FLOPs，平均成功率 82.5% vs 稠密 85.0%，损失 2.5 个百分点，且仿真参数无需调优。
- **延迟加速**：在默认配置下 CUDA 延迟提升 1.23×；随视觉上下文增大（4×、9×），加速比接近理论上限（1/ρ̄），最大达 1.67×。
- **消融结论**：纯随机选择成功率仅 26.9%；变化类信号（像素差、潜在惊喜、oracle KV 漂移）均停留在 60–65%；动作注意力单独可达 81.5%；联合惊喜与注意力达 88.4%；加上年龄上限（G=2）后达到 88.36%，证明强制刷新必要性。

## 相关工作脉络
- **World Action Models**：将视频 DiT 与动作专家结合，Fast-WAM 去除了未来想象只需单次预填充，使预填充成为主要瓶颈；本文首次针对该瓶颈设计训练免费加速。
- **Efficient Policy Inference**：重训练方法（蒸馏、压缩）与训练免费方法（去噪缓存、分块缓存）均不能稀疏化视频 DiT 预填充；本文填补该空白。
- **Token Reduction & Caching**：FastV/ToMe 在帧内剪枝/合并 token；Eventful Transformer/VLA-Cache 跨帧复用静态 token，但无重用期限；本文通过注意力+年龄上限实现有界复用，更适合解耦的 WAM 架构。
- **LLM KV Caching**：LLM 推理中 prompt 固定可精确复用 KV；WAM 每块观测不同，需智能选择刷新集；本文启发式地借鉴了该思想并针对动态视觉观测做了适配。
- **VLA-Cache**：同样结合变化信号与注意力，但注意力来自语言 token 而非动作专家，且无年龄上限；本文证明动作专家注意力更有效，且年龄上限能突破性能天花板。

## 局限性与未来方向
- **小 token 数下加速未达理论上限**：由于 GPU  kernel 启动开销等固定成本，在默认视觉 token 数（120）时实际加速比低于 FLOPs 节省比例；随着 token 数增长（更高分辨率、多视角）应逐渐收敛。
- **未探索与其他加速技术的组合**：本文仅与扩散步数减少结合，未测试与模型蒸馏、异步执行等方法的协同。
- **超参数需简单调整**：不同场景（如随机化）下惊喜预算 b_s 需适当扩大，但年龄上限 G=2 在所有实验中保持固定。
- **未处理长程依赖累积误差**：年龄上限虽抑制误差，但仍假设局部短期误差可接受；对于需要长期精确状态的任務可能存在局限。

## 研究启发与可借鉴点
- **刷新策略应聚焦下游敏感度而非局部变化**：在解耦架构（编码器-动作专家分离）中，策略注意力是更可靠的缓存失效指标，可推广至其他视觉-动作系统。
- **年龄上限是突破性能天花板的简洁手段**：单纯依赖内容信号存在自我referential误差累积问题；引入简单计数约束即可几乎封闭与稠密模型的差距，设计类似缓存系统时可借鉴。
- **多信号联合选取互补子集可提升鲁棒性**：潜在惊喜覆盖动态区域，动作注意力覆盖静态关键区域，两者交集小且并集开销低；该组合思想适用于任何需要稀疏更新的视觉 token 任务。
- **训练免费方案可直接部署于现有 WAM**：无需重新训练，利用已计算的交叉注意力图，与扩散步数减少、模型蒸馏正交，易于工程集成。
- **理论成本分析指导实践选择**：给出精确的 FLOPs 节省公式与刷新比例上界，有助于在accuracy-efficiency trade-off中做理性决策。

## 关键术语表
- **World Action Model (WAM)**：将预训练视频生成 Diffusion Transformer 与动作专家结合的机器人控制框架，通过视频表征引导动作生成。
- **KV Caching**：缓存 Transformer 的键值对以避免重复计算，在 LLM 推理中常见，此处扩展至视觉观测动态变化的 WAM 场景。
- **Prefill**：视频 DiT 将当前观测编码为层级 KV 表示的前向传播过程，是 WAM 每块推理的主要计算开销。
- **Latent Surprise**：基于 token 嵌入与参考嵌入的归一化距离，衡量特征漂移程度的刷新信号。
- **Action‑Conditioned Selection**：利用动作专家上一块的交叉注意力质量选择对下游控制最关键的 token 进行刷新。
- **Age Bound**：限制单个 KV 对最大连续复用块数的机制，强制周期性刷新以防止误差累积。
- **Fast‑WAM**：去除未来想象、仅依赖单次视频 DiT 预填充的 WAM 高效变体，本文加速的目标基线。
- **RoboTwin 2.0 / LIBERO**：用于评估双臂与单臂机器人操作能力的基准测试套件。
