# 论文速读：VAMR: Multi-Question Agentic Reasoning for Efficient Long-Form Video Understanding

## 一句话总结
本文提出 VAMR，首个在多问题场景下用**共享工具调用轨迹**协调多个问题的视频智能体，通过问题条件感知、分层记忆及 QHPO 训练策略，在 LVBench 等三个基准上以最高精度实现最少推理轮数，相比最强基线 VideoARM 推理轮数减少 85.9%、处理帧数减少 61.4%，同时精度提升 4.3 点。

## 研究问题与动机
1. **多问题重复探索问题**：已有视频智能体对同一视频的多问题采用独立 ReAct 循环，每次重启视频探索和记忆构建，浪费大量视觉计算。
2. **缺乏跨问题证据协同**：独立循环下，一个问题获得的视觉证据无法被其他问题复用，无法共同引导证据获取、逐步构建视频的整体理解。
3. **长视频理解的双重挑战**：长视频（平均 68 分钟）包含高密度问题（平均 15 个问题/视频），现有方法在准确性与效率之间难以兼顾。
4. **多目标异步终止的信用分配难题**：同一共享轨迹中，不同问题在不同轮次完成，如何为每个问题正确分配回报信号仍缺乏有效机制。

## 核心贡献（创新点）
1. **首个共享轨迹多问题视频智能体**：提出 VAMR，将多问题推理建模为单次共享的 ReAct 循环，问题作为独立决策目标保持异步终止；与 VideoARM/DVD 等逐问独立优化的方法本质不同。
2. **问题地平线策略优化（QHPO）**：引入问题级 Critic 估计每个活跃问题的优势值，通过轮次对齐（round alignment）将每问题的优势仅分配给直接为其服务的轮次再聚合，解决多目标异步终止的信用分配问题；区别于标准 PPO 对共享轨迹仅使用单一轮次级价值估计。
3. **问题条件感知（QA-inspector）与分层记忆**：单次工具调用同时返回共享片段摘要与每个目标问题的细粒度线索，配合共享故事层+问题线索层的分层记忆，使跨问题证据复用与问题专属证据隔离共存；不同于通用视觉 inspector 仅返回无条件的片段描述。
4. **两阶段 SFT 初始化协议**：Stage 1 利用特权信息（正确答案+证据区间）指导联合动作选择，Stage 2 去除特权信息生成推理轨迹；区别于直接将标注答案注入 policy 输入的做法。
5. **系统的定量分析**：在问题密度、证据重叠度等多个维度进行控制实验，证明 VAMR 的增益不依赖高证据重叠，且随问题密度增加而持续提升。

## 方法详解
**共享循环建模（Section 3.1）**：设视频 $V$ 有 $n$ 个多选问题 $Q=\{q_i\}_{i=1}^n$，在时刻 $t$，策略从活跃问题窗口 $B_t \subseteq Q$ 中选择联合动作 $\mathbf{a}_t$，可同时包含多个问题的答案提交和工具调用：$\mathbf{a}_t \subseteq \{\text{answer}(\hat{y}_i), \text{visual-inspector}(V_{[l,r]}), \text{ASR}(V_{[l,r]})\}_{q_i \in B_t}$。答案提交后该问题退出窗口，从队列后备补入新问，直至所有问题完成。

**QA-inspector（Section 3.2，式 3）**：给定时间区间 $V_{[l,r]}$ 和目标问题集 $Q_t^{\text{tar}}$，输出共享摘要 $g_t$ 和各问题独立线索 $\{e_t^i\}$，单次调用为多个问题同时提供细粒度判别性证据。

**分层记忆（Section 3.2，式 4）**：$M_t = (G_t, \{E_t^i\}_{q_i \in B_t}, T_t)$，其中 $G_t$ 为可复用的视频故事层（时间锚定），$E_t^i$ 为问题 $q_i$ 的专属线索记忆，$T_t$ 为待整合的观察缓冲区。答案确认后整合缓冲内容，清空已完成问题的线索记忆。

**两阶段 SFT（Section 4.1）**：Stage 1 以 $(B_t, M_t, P_t)$ 选联合动作 $\mathbf{a}_t^\star$（$P_t$ 含正确答案和标注证据区间）；Stage 2 去除 $P_t$ 生成推理轨迹 $z_t^\star$。特权信息仅用于指导动作选择，不进入 policy 输入。

**QHPO（Section 4.2）**：
- **问题级 Critic**：$V_\phi(B_t, M_t, q_i) \in (0,1)$ 估计问题 $q_i$ 的胜率，训练损失为二元交叉熵（式 6）。
- **问题级 GAE**：对每个问题 $q_i$，在其活跃回合 $[s_i, e_i]$ 内用 critic 值计算优势 $A_{t,i}$，其中终止回合赋真实奖励 $R_i \in \{0,1\}$，之后归零（式 E.9 附录）。
- **轮次对齐**：仅当回合 $t$ 的联合动作直接服务于 $q_i$ 时保留 $A_{t,i}$，否则置零；非空时取平均得回合级优势 $A_t = \frac{1}{|S_t|}\sum_{i \in S_t} A_{t,i}$（式 7）。
- **Actor 更新**：标准 clipped PPO（式 8），$\epsilon=0.2$，KL 系数 0.02，LoRA rank=64/scale=128，学习率 $10^{-6}$（actor）/$10^{-4}$（critic）。

**推理配置（附录 C）**：活跃窗口固定 5 个，最大回合 $T_{\max}=\max(12, 4|Q|)$，每回合最多 6 次工具调用，每帧调用采样 30/60/90/150 帧，细粒度查询不超过 30 秒，ASR 不超过 90 秒。

## 实验与结果
**数据集**：训练仅用 CG-Bench（1,219 视频，SFT 5,775 问实例，QHPO 6,001 问实例）；评测集为 LVBench（103 视频，平均 15.04 问/视频，68.4 分钟）、Video-Holmes（270 视频，6.8 问/视频，2.8 分钟）、LongVideoBench（753 视频，1.78 问/视频，7.9 分钟）。

**基线**：Video-R1、DeepVideo-R1、FrameThinker、TimeSearch-R、DVD、VideoHV-Agent、VideoARM；自制独立循环对照（Ind. Loops SFT+PPO）。

**主要结果（Table 1）**：
- **LVBench**：VAMR **62.1%**，超越 VideoARM（57.8%） **+4.3 点**；Rounds/Q = **0.9**（VideoARM 6.4，**-85.9%**）；Frames/Q = **84.9**（VideoARM 220.2，**-61.4%**）。
- **Video-Holmes**：VAMR **58.2%**（+4.4 点 vs Ind. Loops）；Rounds/Q 1.4（-54.8%）；Frames/Q 98.4（-29.0%）。
- **LongVideoBench**：VAMR **66.5%**（+1.4 点 vs Ind. Loops）；Rounds/Q 1.8（-57.1%）；Frames/Q 175.0（-9.0%）。

**消融（Table 7-8）**：
- 架构：共享循环→+4.4 点/-66.7% Rounds；QA-inspector→+4.3 点；分层记忆→+2.7 点；全架构→+11.6 点/-72.9% Rounds vs 独立循环。
- 训练：SFT→57.9%；PPO→58.7%；QHPO w/o 对齐→60.0%；QHPO 全→**62.1%**（比 PPO +3.4 点，对齐贡献 +2.1 点）。

**扩展分析（Figure 4）**：
- 问题密度：从 1 到 16 问/循环，精度 58.1%→62.8%，Frames/Q 219.2→87.7。
- 证据重叠：Q1（最低，仅 1.4% 对重叠）VAMR 仍提升 **+7.0 点**、减少帧数 63.4%，证明增益不依赖高证据重叠。

## 相关工作脉络
1. **VideoARM（Yin et al., 2026）**：在线分层记忆+按需感知工具的 agentic 方法，但每个问题独立运行循环；VAMR 将其改为单共享循环，允许跨问题复用观测并异步终止。
2. **DVD（Zhang et al., 2025）**：预建视频数据库+语义 clip 搜索；VAMR 不使用预建数据库，而是在线协调多问题共同指导证据获取。
3. **FrameThinker / TimeSearch-R（He et al., 2025; Pan et al., 2025）**：迭代搜索方法，面向单问题；VAMR 将迭代搜索扩展为多问题共享的联合搜索。
4. **Video-R1 / DeepVideo-R1（Feng et al., 2025a; Park et al., 2025）**：端到端固定上下文推理，无法自适应检索；VAMR 通过 agent 循环主动检索所需证据。
5. **UniVA（Liang et al., 2025b）**：将多个问题打包为单一复合目标一次推理返回；VAMR 保持问题作为独立决策目标贯穿推理全程，支持异步终止和差异化证据需求。
6. **交叉问题信息利用（Lei et al., 2020; Pei et al., 2025）**：将问题间语义关系作为辅助信息用于一次预测或特征提取；VAMR 将这些关系内化为共享循环中的联合策略决策。

## 局限性与未来方向
1. **适用场景限制**：聚焦"同一视频的多个不同方面"的多问题设定，对于跨视频联合推理或单问题场景扩展性有限（Section A）。
2. **共享轨迹的扩展算法**：仅探索了 QHPO 一种策略优化方法，可进一步探索适合共享多问题轨迹的其他 off-policy 或 hierarchical RL 算法。
3. **窗口大小固定为 5**：活跃窗口固定 5 个问题，对于超高密度场景可能需要自适应窗口调度策略。
4. **未涉及开放域多模态输出**：当前仅支持多选题，不支持自由文本生成类问题。

## 研究启发与可借鉴点
1. **共享轨迹多任务协调模式可迁移**：将"共享 ReAct 循环 + 异步终止"范式应用于文档理解、代码调试等多子任务场景，可借鉴其队列管理（backlog）和窗口调度设计。
2. **两阶段 SFT 特权信息剥离策略**：Stage 1 用标注信息指导动作选择、Stage 2 去除标注生成推理，可有效训练政策模型在不依赖特权信息下自主推理，适用于其他 agent SFT 流程。
3. **轮次对齐信用分配机制**：QHPO 的"按直接服务轮次对齐 + 聚合"思路可推广至任何多目标共享轨迹的 RL 训练，如多文档检索、多步骤编程任务。
4. **问题条件感知工具设计**：将问题文本和选项注入视觉工具 prompt 以提升检索判别性，可推广至任何需要细粒度证据定位的多任务 VQA 系统。
5. **分层记忆（共享故事 + 专属线索）结构**：通用izable 的 memory architecture，适用于任何需要共享上下文与个体证据区分的长程推理 agent。

## 关键术语表
**VAMR**：Video Agent for Multi-Question Reasoning，本文提出的首个在多问题场景下用共享轨迹协调推理的视频智能体。
**共享循环（Shared Loop）**：将所有问题纳入同一 ReAct 推理环，策略在每个回合同时决策多个问题的答案提交与工具调用，而非逐问独立循环。
**QHPO（Question-Horizon Policy Optimization）**：针对共享多问题轨迹的策略优化算法，通过问题级 Critic 和轮次对齐实现多目标异步终止的信用分配。
**QA-inspector**：问题条件感知工具，单次调用接收时间区间和多个目标问题，返回共享片段摘要和各问题的细粒度判别线索。
**分层记忆（Layered Memory）**：由共享故事层 $G_t$、各问题专属线索层 $E_t^i$ 及观察缓冲区 $T_t$ 构成的三层记忆结构，支持跨问题复用与问题专属隔离并存。
**轮次对齐（Round Alignment）**：将问题级优势 $A_{t,i}$ 仅保留在回合 $t$ 的联合动作直接服务于 $q_i$ 的回合，其他回合置零后再聚合。
**活跃问题窗口（Active Question Window）**：当前暴露给策略模型的 5 个未解决问题，其余问题保持在有序队列（backlog）中等待补入。
**Rounds/Q & Frames/Q**：推理效率指标，分别为每个问题平均消耗的推理回合数和视觉模型处理的帧数。
