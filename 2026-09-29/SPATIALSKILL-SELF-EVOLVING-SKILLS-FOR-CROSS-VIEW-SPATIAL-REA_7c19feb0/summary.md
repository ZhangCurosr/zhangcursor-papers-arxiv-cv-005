# 论文速读：SPATIALSKILL: SELF-EVOLVING SKILLS FOR CROSS-VIEW SPATIAL REASONING

## 一句话总结
SpatialSkill 是一种无需参数更新的框架，使冻结的视觉语言模型（VLM）能够从离线推理轨迹中积累显式的自然语言推理技能。该方法通过地面验证准入、稳定性约束演化和类别条件化路由三个核心机制，在不修改模型权重的情况下持续提升跨视角空间推理能力，并在 CityCube 上使 9B 模型超越最强闭源基线。

## 研究问题与动机
- **跨视角空间推理的困难**：人类能自然地将不同视角（如航拍与地面）对齐为连贯的空间表征，但当前 VLM 在需要视角变换和跨视角对齐的任务上表现仍然较弱。
- **现有方法依赖参数更新**：主流方案通过强化学习、监督微调或预训练更新模型权重，将知识隐式编码在特定骨干网络中，导致策略难以独立检查、修订或复用。
- **感知技能缺乏可靠验证**：与符号任务可通过执行直接验证不同，视觉感知识能（如"某空间规则"）可能听起来合理但缺乏视觉证据支持，或需要冻结模型无法完成的操作。
- **技能积累的有害交互**：反复修订可能累积噪声、产生意外交互或错误删除有用规则，且统一部署技能可能对不同推理类别产生负面迁移。

## 核心贡献（创新点）
- **首次研究冻结 VLM 的自我演化显式技能**：在真实跨视角空间推理场景下，识别出可靠性所需的三个条件——地面验证准入、稳定积累、条件化部署，现有工作未同时覆盖。
- **提出三层保障的 SpatialSkill 框架**：通过地面验证准入门（视觉支持 + 可执行性）、稳定性约束演化（增长预算、资历保护、探测分数棘轮）、类别条件化路由联合解决上述三个挑战，而已有技能积累方法多依赖可执行工件或参数更新。
- **零参数更新的性能突破**：在 CityCube 上使四个冻结执行器均获得 2.65–4.92pp 提升；9B 模型搭配 SpatialSkill 达到 57.58%，超越 GPT-5.6-sol 和 Qwen3.7-plus（均为 56.06%）这一最强闭源基线。
- **可审计的版本化技能手册**：推理策略以结构化自然语言存储于版本化手册中，支持追溯、检查和撤回，区别于参数化知识的黑箱特性。

## 方法详解
**整体流程**（三个阶段）：
1. **推理轨迹采集**：冻结 VLM executor 生成跨视角推理轨迹。
2. **技能演化**：对轨迹窗口进行反思，生成候选修订，经准入门和稳定性约束后更新版本化手册。
3. **条件化部署**：按推理类别路由选择最优推理策略。

**3.2 技能反思与地面验证准入**
- 维护结构化技能手册 $M$，含规划、跨视角对齐、空间推理、失败规避四大章节及执行说明。
- 反射模型 $\Phi$（固定，不参与训练）基于当前手册 $M_{w-1}$ 和轨迹窗口 $T_w$ 生成候选修订 $\Delta_w$，支持四种操作：添加技能、改写技能、修正技能、添加执行说明。
- 准入门 $\mathcal{G}(r) = \mathcal{V}(r) \wedge \mathcal{E}(r)$：$\mathcal{V}(r)=1$ 要求规则有视觉证据支持；$\mathcal{E}(r)=1$ 要求操作在冻结 executor 能力范围内。只有通过两项检查的候选才能进入临时手册。
- 执行级别修订仅更新执行说明，防止偶发噪声污染可复用技能规则。

**3.3 稳定性约束的技能演化**
- 在独立保留探测集 $P$ 上评估临时手册准确率：
$$A(M) = \frac{100}{|P|} \sum_{x \in P} \mathbf{1}\{\hat{y}_M(x) = y(x)\}$$
- **增长预算**：限制每窗口净增规则数 $|M_w| - |M_{w-1}| \leq \beta$，防止过度膨胀导致频繁压缩。
- **资历保护**：存活超过 $\tau$ 个窗口的规则不受盲目压缩删除，除非有证据定向修订。
- **探测分数棘轮**：只有临时手册得分不低于历史最佳减容忍阈值（$b_{w-1} - \varepsilon$）时才接受更新；否则维持上一版本，并记录历史最高分 $b_w = \max\{b_{w-1}, A(M_w)\}$。形成容差带不变量 $A(M_w) \geq A_w^\star - \varepsilon$。

**3.4 类别条件化技能部署**
- 推理类别共五类：心理重建（MR）、视角转换（PT）、空间关系（SR）、世界知识（WK）、综合推理（CR）。
- 路由策略从 $\mathcal{S} = \{0,1\}^2$ 中选择：$i=0/1$ 表示直接回答/链式思考（CoT），$j=0/1$ 表示无手册/使用手册。
- 基于 Wilson 置信区间保守切换：仅当候选策略下界超过默认策略上界至少 $\delta$ 时才切换，避免探测采样噪声导致的过选择。

## 实验与结果
- **数据集**：CityCube（官方 4,494/528 train/val 分割），另用 MMSI-Bench 的 1,000 样本做外部迁移验证。
- **冻结执行器**：Qwen3.5-4B、Qwen3.5-9B、Gemma-3-4B、GPT-5.6-luna；反射模型统一用 Qwen3.5-9B（本地服务）。
- **主要结果**：
  - Qwen3.5-4B：47.16% → 52.08%（+4.92pp）
  - Qwen3.5-9B：54.55% → 57.58%（+3.03pp）
  - Gemma-3-4B：49.24% → 51.89%（+2.65pp）
  - GPT-5.6-luna：53.79% → 56.82%（+3.03pp）
  - **最强结果**：9B 模型 57.58%，超过 GPT-5.6-sol 和 Qwen3.7-plus（56.06%）1.52pp，仅落后 Qwen3.5-27B（58.14%）0.56pp。
- **类别差异**：Qwen3.5-4B 在 SR（+10.57pp）和 WK（+11.72pp）上增益最大，但在 CR 和 MR 上略有下降，印证类别条件化部署的必要性。
- **选项一致性**：四组配对执行器的 option-wise accuracy range 均缩小（如 Qwen3.5-4B 从 27.28pp 降至 23.52pp），精度提升未伴随更大的选项依赖差异。
- **消融**：移除联合准入门、移除探测棘轮（Naive）均有显著损失；Stability controls 三组件作用互补。
- **稳定性诊断**：SpatialSkill 将重构事件窗口从 35 降至 6（Qwen3.5-4B），24 降至 8（Gemma-3-4B）。
- **跨模型迁移**：8 组跨执行器迁移均带来 0.57–6.82pp 提升（均值 2.72pp）；外部 MMSI-Bench 迁移 Qwen3.5-4B +2.00pp、GPT-5.6-luna +4.10pp。
- **反射模型敏感性**：换用 Qwen3-4B/8B 仍可获 +3.41/+1.89pp 提升，证明框架对反射模型选择不强依赖。

## 相关工作脉络
- **空间推理 VLM 方法**：包括 SpatialThinker（空间奖励 RL）、SpatialVLM（端到端空间能力注入）、SpatialBot（深度信号注入）等，均以参数/表示更新为核心手段；本文与它们本质区别在于不修改权重，以显式自然语言手册替代隐式参数知识。
- **自演化智能体/技能库**：SkillRL、SkillWeaver、EmbodiSkill 等工作通过 RL 递归增强或从资源中提取 API 级可执行技能；本文处理的是不可直接执行的感知类技能，且目标为冻结 VLM，不涉及训练循环。
- **ACE（Agentic Context Engineering）**：在文本任务上积累可复用经验教训，但与本文的关键差异是 ACE 面向文本任务评分，本文解决感知空间中无直接 rule-level verifier 的 admission 难题。
- **空间专用模型**：Spatial-SSRL、SpaceR-SFT、ViLaSR 等均在 50% 以下，本文 frozen executor + SpatialSkill 仍超过这些专门训练的空间模型。
- **多视角空间基准**：ViewSpatial-Bench、OmniSpatial、Esi-Bench 等侧重于评测视角，本文针对 CityCube 的跨视角对齐与变换任务提出新的增强范式。

## 局限性与未来方向
- 当前路由依赖预计算的 CvSI 类别标注，无法完全端到端自主决策。
- 自然语言手册仅优化推理策略，不增强 executor 的底层视觉表征能力；与人脑 88.3% 准确率相比仍有 30pp 以上差距。
- 视角转换（PT）类任务仍是明显瓶颈（最佳非人结果 51.9% vs 人类 87.4%）。
- 论文自述未来方向：探索将显式手册作为 fine-tuning prior，结合显式技能与隐式参数更新。

## 研究启发与可借鉴点
- **地面验证准入门设计**：视觉证据支持（$\mathcal{V}$）+ 可执行性（$\mathcal{E}$）的双约束机制，可迁移至其他感知类技能的积累场景（如视觉问答、场景理解），防止"听起来合理但无法验证"的技能污染知识库。
- **三层稳定性控制框架**：增长预算、资历保护、探测分数棘轮的组合策略具有通用性，适用于任何需要增量更新知识库且无全局最优 oracle 的持续学习系统。
- **类别条件化路由思想**：不同任务类别适配不同推理策略（直接/CoT × 有/无手册），避免统一策略的负迁移，对多任务 VLM 部署有直接参考价值。
- **可审计版本化手册**：以自然语言 + 版本管理存储推理策略，为模型可解释性和安全审查提供新路径，可与知识图谱/文档管理工具结合。
- **跨模型/跨数据集迁移验证**：本文展示了 skill manual 在不同 executor 和不同数据集（CityCube → MMSI-Bench）上的迁移能力，为"一次积累、多处复用"的高效技能流水线提供了实证范式。

## 关键术语表
- **跨视角空间推理（Cross-view Spatial Reasoning）**：要求模型在航拍/地面等多个视角之间进行空间变换和对齐，以回答关于场景结构、方向和关系的问题。
- **地面验证准入门（Grounded Admission Gate）**：通过视觉证据检查（$\mathcal{V}$）和可执行性检查（$\mathcal{E}$）双重过滤候选技能，确保只有有视觉支撑且 executor 可执行的规则进入手册。
- **探测分数棘轮（Probe-Score Ratchet）**：以保留历史最佳探测分为基准，设置容忍阈值 $\varepsilon$，拒绝导致性能大幅下降的修订，防止有害更新被部署。
- **类别条件化路由（Category-Conditioned Routing）**：根据空间推理的五种类别（MR/PT/SR/WK/CR）分别选择最优的推理策略组合，避免统一策略带来的负迁移。
- **资历保护（Seniority Protection）**：对存活超过 $\tau$ 窗口的稳定规则给予豁免，防止压缩过程中误删有价值的长期规则。
- **增长预算（Growth Budget）**：限制每窗口手动册净增规则数 $\beta$，控制手册膨胀速度，延缓触发压缩的频率。
- **Versioned Natural-Language Manual**：以结构化自然语言存储、支持版本管理的技能手册，使推理策略可审计、可追溯、可撤回。
- **Option-wise Accuracy Range**：衡量模型在不同预测选项上的条件准确率极差，反映答案选项依赖性；本文使用该指标验证精度提升未以选项偏差为代价。
