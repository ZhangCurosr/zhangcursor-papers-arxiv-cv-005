# 论文速读：SPOC-Net-Single-Primitive-Online-Composition-Network-for-GNS

## 一句话总结
SPOC-Net 将 GNSS 干扰信号识别任务分解为对基本干扰原语的集合识别，仅使用实测的单组分 IQ 记录进行梯度优化，通过在线 IQ 组合器生成训练用混合样本，并结合组件查询与结构化解码实现对未见组合的组配泛化。在 14,220 条实测混合射频记录上达到 80.69% 精确集准确率，在完全排除于模型开发之外的六组组合上达到 80.89%，领先最强基线 18.77 个百分点。

## 研究问题与动机
- GNSS 干扰识别对自动驾驶、智能交通和空天地一体化网络的安全运行至关重要；但现有学习方法大多采用闭合类别列表，每种混合组合对应独立类别，扩展到新的组合需重新标注和重新训练。
- 随着原语类型数 C 增加，有效混合类别数可达 $2^C - 1$，实测混合数据集的采集成本极高，需要多源协同生成、精确功率关系设定和反复捕获验证。
- 雷达领域的多标签学习和组合泛化研究表明，按组件逐项输出可以复用单一原语表示，并在训练未覆盖的组合上保持识别能力，但此类思路尚未在 GNSS 干扰识别中被系统验证。
- 现有混合干扰方法往往依赖固定的混合训练集，未能回答"是否可在仅有单组分实测样本下进行梯度优化，并在未知组合上迁移"这一核心问题。

## 核心贡献（创新点）
- **在线干净 IQ 组合器**：仅用实测单组分 IQ 序列按需合成带标签混合样本，避免为每个混合组合单独采集射频数据。区别于传统方法对固定混合数据集的依赖。
- **SPOC-Net 联合识别框架**：坐标感知多分辨率编码器、学习型原语查询、脱离梯度的高分辨率基数分支与结构化候选集打分联合工作。区别于仅做多标签逐类独立决策的方法。
- **训练集-留置组合严格分离协议**：十组组合参与辅助训练和模型选择，六组组合完全排除于梯度优化、早停、超参调优与解码器校准之外，专门测试已知原语新组合的泛化能力。区别于以闭合集合精度为主的评测惯例。
- **配对损失与层次基数训练**：通过两/三组分配对样本约束添加第三组件后的证据单调性，并通过条件概率实现二/三组分基数估计。区别于独立阈值截断的判别方式。
- **实测导引的端到端评测平台**：构建包含活体 GNSS 信号与可达三组分人工干扰的合成射频链路，形成可复现的 conducted RF 基准。区别于纯数值仿真驱动的研究。

## 方法详解
- **时频表示**：对 1 ms、采样率 20 MHz 的复基带 IQ 记录做 STFT，Hann 窗 128 采样点、重叠 118、步长 10，FFT 长度 $N_f = 4096$；对压缩对数幅度映射到 $224 \times 224$ 单通道灰度图，并附加时间与频率坐标增强图。
- **在线组合器**：对每个选中的训练列组合 $\mathcal{K}$，从存储的干净单组分 IQ 序列中分别做去均值和 RMS 归一化后按相对功率 $a_i = 10^{\rho_i/20}$ 加权叠加，再生成新背景高斯噪声并组合；JNR 从 $\{-20,-15,-10,-5,0,5,10,15\}$ dB 中采样，相对功率在 $[-6, 6]$ dB 范围内采样，组合发生在 STFT 之前而非谱图相加之后。
- **共享频谱-时间编码器**：将坐标增强后的 STFT 输入多尺度并行卷积茎（核集合 $\mathcal{R}=\{3,5,11\}$，stride 4），经四个阶段得到 $1/4, 1/8, 1/16, 1/32$ 下采样特征；通过自适应平均池化与一个各向异性上下文单元进行多尺度融合。
- **原语证据分支**：在多尺度 token 网格上追加层级嵌入后拼接全局 GAP 描述符，作为 Cross-Attention 的键值源；每条原语分配一个可学习 query，经两层含 CA-SA-FFN 的解码层收集跨层级证据；最终 logits 为 query-conditioned 项与全局项 $\alpha_g=0.35$ 的加权和，并用 ASL 损失训练。
- **高分辨率基数分支**：从原始 STFT 图像路径与经过 stop-gradient 保留的浅层特征 $F_1$ 中提取高分辨率证据，分别经 GeM、max 和 attention pooling 后拼接全局描述符与排序后的原语 logit/概率轮廓，再经预测器输出混合 logits $u_{\mathrm{mix}}$ 与条件 logits $u_{3|\mathrm{mix}}$。
- **结构化候选集解码**：对每个候选混合掩码计算加权 Bernoulli log-score $\mathcal{B}(A|X)$，并与先验基数概率 $\overline{p}_{|A|}$ 及三组分偏好项 $\frac{\beta_3}{T_c}\mathbb{I}(|A|=3)$ 相加得到 $S_{\mathrm{mix}}(A|X)$，最后在 16 个合法两/三组分候选中取最大值作为预测集合。
- **训练目标**：由四部分组成，$\mathcal{L}=\lambda_{\mathrm{cls}}\mathcal{L}_{\mathrm{cls}}+\lambda_{\mathrm{set}}\mathcal{L}_{\mathrm{set}}+\lambda_{\mathrm{card}}\mathcal{L}_{\mathrm{card}}+\lambda_{\mathrm{pair}}\mathcal{L}_{\mathrm{pair}}$，权重默认 $(1.00, 0.25, 0.50, 0.15)$；集合损失在训练候选集 $\mathcal{A}_1 \cup \mathcal{A}_{\mathrm{list}}$ 上做 softmax；配对损失对每对两/三组分样本施加 margin 约束，鼓励加入第三组分后条件 logit 单调上升。
- **解码器校准**：在训练列表开发集上离散搜索 $(T_c,\lambda_c,\beta_3)$，并以两组分精确集准确率为安全下限，字典序优化三组分准确率、平衡准确率与总准确率。

## 实验与结果
- **数据集与协议**：共采集 14,220 条独立混合记录，覆盖 16 种两/三组分合法组合，JNR 范围 $-20$ 至 $15$ dB（步长 5 dB）。其中十组列为训练列组合 $\mathcal{A}_{\mathrm{list}}$（8,887 条），六组为留置组合 $A_{\mathrm{hold}}$（5,333 条）；所有开发决策和最终测试均严格遵守列/留置分区。
- **评估基线**：六种五标签多输出适配模型，包括 AlexNet-ML、ResNet18-ML、Feature-ResNet18-ML、ACSNet-ML、MSFF-KAN-ML 与 TS-FANet-ML；均采用相同 STFT 输入、随机初始化、相同增强策略与 120 轮 AdamW 训练，使用单视图推理。
- **主要结果**：全混合集上 SPOC-Net 达到 exact-set accuracy 80.69%、micro-F1 92.84%、cardinality accuracy 87.08%。训练列组合上 80.57%，留置组合上 80.89%。最强对比方法 ResNet18-ML 在留置组合上仅达 62.12%，SPOC-Net 提升 18.77 个百分点。
- **JNR 依赖**：非负 JNR 下 exact-set 准确率 $\geq 99.49\%$；在 $-15$ dB 时两/三组分准确率分别为 82.65% 与 11.60%；在 $-5$ dB 时恢复至 99.40% 与 91.93%。低 JNR 下三组分识别是主要瓶颈。
- **错误结构**：基数错误主要表现为低估（真实三组分被预测为两组分的比例 28.86%），遗漏的原语多为 PBNJ 或 LFMJ；STJ+PTJ 在留置组上达到 87.74%，而最强基线在同一组仅为 19.8%。

## 相关工作脉络
- **闭合集 GNSS 干扰识别**（如 ACSNet、指纹谱 DNN、TS-FANet）：以往方法以单分类或固定混合类列表输出为主，适用于既定分类体系，但对新增组合的泛化能力受限；本文以组件级输出替代固定混合类别。
- **复合干扰识别与多标签雷达研究**：Object-detection 与专用卷积网络用于复合识别，雷达领域的多标签学习与组合泛化表明组件复用可行；本文将其迁移到 GNSS 且区分离线混合监督与在线组合训练的差异。
- **物理测量数据驱动的 GNSS 干扰**：已有研究强调实测干扰的必要性，并关注低资源与 few-shot 场景；本文在前人基础上进一步要求模型仅用单组分实测样本进行梯度更新，并将实测混合仅用于开发与最终测试。
- **Query-based 多标签解码**（Query2Label、ML-Decoder）：通过可学习 query 从共享特征图中采集证据；本文在此基础上引入脱离梯度的高分辨率基数分支与结构化候选集打分，弥补独立阈值截断无法控制集合大小的缺陷。
- **ASL 与不对称损失在多标签中的应用**：ASL 已在雷达复合干扰中得到使用；本文将其引入 GNSS 五标签原语识别，并结合集合 softmax 与配对约束以同时优化成分识别与集合一致性。
- **组合泛化与开放集识别**：雷达领域已有针对训练外组合与未知原语的工作；本文聚焦于已知原语的新组合泛化，明确将未知原语识别排除在任务定义之外。

## 局限性与未来方向
- **低 JNR 下第三组分识别困难**：在 $-15$ dB 时三组分精确集准确率仅 11.60%，高分辨率分支与配对损失能够缓解但未完全消除弱组分遗漏。
- **固定组合分区与单次运行评估**：仅在一个 10/6 的训练列-留置划分上进行评测，未报告多次运行的不确定性，无法证明对其他划分的稳定性。
- **导引式 RF 平台的物理真实性边界**：conductively combined 链路可复现射频叠加但未能覆盖户外传播、天线方向图变化与多径效应；结果推广到自由空间场景需额外验证。
- **线性组合生成器的物理偏差**：在线 IQ 组合器为线性叠加，未完全复现 RF 合路器损耗、增益漂移与非线性失真，导致训练分布与实测存在差异。
- **解码器功能边界**：当前模型仅在两/三组分合法掩码内搜索，不做无干扰、单组分或未知原语判定，不能直接作为完整干扰监视器使用。

## 研究启发与可借鉴点
- **在线成分组合的数据增强范式**：将已存单组分干净 IQ 序列与可控噪声/功率/JNR 进行 STFT 前叠加，可作为低资源射频场景下的通用训练数据扩充手段，尤其适用于标签成本高的多分量识别任务。
- **组件证据与基数估计解耦设计**：用 stop-gradient 保留高分辨率路径用于集合大小先验，同时让共享编码器专注成分识别，避免了参数竞争导致的表征退化；该思路可迁移到其他需要识别"有多少对象"的多标签场景。
- **结构化候选集打分优于独立阈值**：在所有合法组合掩码上评分并取最大值的解码方式，能自动满足集合大小与互斥约束，在已知原子类但未知组合的任务中具有通用价值。
- **配对单调性损失增强层次识别**：通过两/三组分配对样本施加条件 logit 单调约束，可稳定添加第三组件后的识别行为；对任何需要估计成分数量的检测任务均有参考意义。
- **开发-测试组合分区的严格隔离协议**：将完全排除于任何开发决策之外的组合作为最终测试集，可以更可信地度量组配泛化，适合需要对外部组合泛化能力的任何数据集构建方案。

## 关键术语表
**Single-Primitive（原语）**：指五种基本 GNSS 干扰波形类型之一，包括单音、多音、线性调频、脉冲tone和部分带噪声。
**Online Composition（在线组合）**：在训练加载时按需从存储的干净单组分 IQ 序列合成带标签混合样本，而非预先构建固定混合数据集。
**Cardinality（基数）**：单条记录中同时激活的原语类型数量，本文任务中取值为 2 或 3。
**ASL（Asymmetric Loss，非对称损失）**：通过幂次调节正负样本梯度贡献，减轻易负样本对多标签训练的干扰。
**GeM Pooling（广义均值池化）**：以幂次 $p$ 对特征做平均，介于均值与最大值之间，用于聚合高分辨率特征中的分布式能量。
**Stop-Gradient（停梯度）**：在反向传播时阻断梯度沿某条路径流动，使该分支仅在前向阶段使用上游特征而不更新共享编码器。
**Exact-Set Accuracy（精确集准确率）**：预测的多热标签向量与真实向量完全一致的比例，要求成分身份与集合大小均正确。
**Conducted RF（导引射频）**：通过射频合路器有线注入信号而非空口辐射的测试方式，具有可重复但不完全复现自由空间传播的特性。

## 可复现要素
- **数据集**：14,220 条独立采集的导引混合记录，采样率 20 MHz，每记录 1 ms；单组分实测训练记录用于梯度优化，十组列为训练列混合用于开发与选择，六组留置组合仅用于最终测试。论文未声明开源仓库，但提供了平台连接关系与参数细节。
- **代码/权重**：论文未公开代码与预训练权重；实现基于 Python 3.11、PyTorch 2.x、CUDA/cuDNN。
- **关键超参**：输入 $224 \times 224$ 灰度 STFT；并行茎核集合 $\{3,5,11\}$ stride 4；阶段深度 $(2,2,6,2)$，通道 $(64,128,256,384)$；解码维度 384，两层解码，6 头；全局系数 $\alpha_g=0.35$；Dropout 0.15、stochastic depth 0.10；训练 120 轮、batch 32、AdamW、学习率 $2.5\times 10^{-4} \to 10^{-6}$、weight decay $7\times 10^{-4}$；EMA 衰减 0.999；$\lambda_{\mathrm{cls}}=1.00$、$\lambda_{\mathrm{set}}=0.25$、$\lambda_{\mathrm{card}}=0.50$、$\lambda_{\mathrm{pair}}=0.15$；ASL $(\gamma_+, \gamma_-)=(0,4)$、$m_a=0.05$；pair margin $m_p=0.50$；相对功率采样 $[-6,6]$ dB；JNR 网格 $-20:5:15$ dB；左尾加权与极低 JNR 加权分别为 1.3× 与 1.8×；测试视图平均次数 4，校准视图平均次数 2。
