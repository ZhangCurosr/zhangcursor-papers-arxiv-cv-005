# 论文速读：SUBROT-SIGNED-GRADIENT-SUBSPACE-CALIBRA-TION-FOR-VLM-ROTATIO

## 一句话总结
本文提出 **SubRot** 方法，通过在通道空间中对经验 Fisher 矩阵进行特征分解，识别出跨样本稳定的敏感子空间，并结合符号稳定的一阶梯度引导与二阶曲率约束，实现 VLM 的低比特旋转量化校准；在 W4A4 设置下，SubRot 的平均精度退化控制在 1.4 个百分点以内，且在 LLaVA-v1.5-13B 上超越 FP16 基线 0.4 个百分点。

## 研究问题与动机
- **模态/token 级梯度统计缺乏跨样本稳定性**：不同样本的 visual-to-textual token 比例和视觉信息位置差异显著，导致基于 token 索引的梯度统计难以泛化到未见样本。
- **绝对值与平均聚合丢失关键信息**：现有方法通过绝对值和通道平均将梯度压缩为标量重要性分数，丢弃了梯度符号信息（影响损失变化方向）和通道间差异，限制了敏感性区分能力。
- **仅追求 FP16 输出近似存在理论瓶颈**：现有方法仅最小化量化误差幅度，未利用误差方向对任务损失的有利影响，理论上制约了量化模型的性能上限。

## 核心贡献（创新点）
- **Fisher 特征分解识别敏感子空间**：通过对经验 Fisher 矩阵做谱分解，提取前 r 个主特征向量构成敏感子空间，相比 C-PTQ 的对角近似能捕获通道间相关性，且具有更强的跨样本稳定性。
- **符号稳定方向的一阶引导机制**：在敏感子空间内识别跨样本符号稳定的梯度方向，沿这些方向施加一阶损失引导量化误差朝向降低自回归损失的方向移动。
- **一阶+二阶联合优化的校准目标**：基于泰勒展开将量化误差分解为符号稳定方向（一阶引导）和符号不稳定方向（二阶曲率约束），并结合 MSE 保持整体重建质量，实现误差的精细塑形。
- **跨模型/跨尺寸广泛验证**：在 5 个 VLM（2B–13B，两类架构）和 5 个基准上系统验证，W4A6 较 FlatQuant 平均提升 0.60pp，W4A4 提升 0.52pp。

## 方法详解
1. **敏感子空间构建**：对第 l 层的经验 Fisher 矩阵 $\mathbf{F}_l = \frac{1}{Z_l} \sum_s (\mathbf{G}_l^{(s)})^\top \mathbf{G}_l^{(s)}$ 进行特征分解，选取前 r 个最大特征值对应的特征向量组成敏感子空间基 $\mathbf{U}_l \in \mathbb{R}^{C \times r}$。
2. **符号稳定方向判定**：验证敏感子空间内是否存在方向 $\mathbf{u}_k$，使得 $\sigma_k \cdot \nabla_{\mathbf{x}} \mathcal{L}^\top \mathbf{u}_k$ 在绝大多数样本中符号一致（图 3 验证了所有层所有样本的 loss 变化均为负）。
3. **优化目标设计**：
   $$\mathcal{L} = \mathcal{L}_{\mathrm{MSE}} + \alpha \cdot \mathrm{Mean}(\Delta \mathbf{Z}_{\mathrm{st}} \odot \pmb{\sigma}) + \beta \cdot \|\Delta \mathbf{Z}_{\mathrm{us}}\|_F^2$$
   其中第一项维持整体重建质量，第二项对符号稳定方向施加一阶引导（$\Delta \mathbf{Z}_{\mathrm{st}}$），第三项对剩余敏感方向施加二阶约束（$\Delta \mathbf{Z}_{\mathrm{us}}$）。
4. **旋转量化框架**：在 FlatQuant 的仿射变换框架内嵌入上述损失，不改变推理计算图，部署效率与 FlatQuant 相当。

## 实验与结果
- **数据集与模型**：校准集为 ScienceQA 128 样本；评估 5 个基准（MMMU、OCRBench、VizWiz、ChartQA、SEEDBench2Plus）；5 个模型（LLaVA-NeXT-7B、Qwen2VL-7B、LLaVA-v1.5-7B/13B、Qwen2-VL-2B）。
- **主要结果**：W4A6 下 SubRot 较 FlatQuant 平均提升 0.60pp；W4A4 下平均提升 0.52pp；LLaVA-NeXT-7B 在 W4A6/W4A4 分别提升 0.9pp/1.4pp。
- **极端场景**：W4A4 下所有模型相对 FP16 退化 ≤1.4pp；LLaVA-v1.5-13B 在 W4A4 下**超越 FP16 0.4pp**。
- **消融**：一阶引导（+0.3pp）+ 二阶约束（+0.5pp）联合使用时达到最佳（46.1 平均分，较 baseline 45.0 提升 1.1pp）。
- **部署效率**：W4A4 下端到端推理时间从 2146.7ms 降至 1303.8ms（-39.3%），峰值显存从 14.9GB 降至 9.7GB（-34.9%），与 FlatQuant 持平。
- **稳定性与可分性验证**：图 2 显示敏感/非敏感划分在分布偏移下 Wasserstein 距离更小，且敏感方向与噪声扰动的 loss 响应比语言/视觉 token 划分更具区分度。

## 相关工作脉络
- **MBQ / QIG**：基于模态或 token 级梯度统计进行重加权，但存在跨样本稳定性不足和符号信息丢失问题；本文转向通道空间并通过特征分解解决。
- **C-PTQ**：使用对角 Fisher 近似估计通道敏感性，本文通过完整 Fisher 矩阵特征分解捕获通道间相关性，且引入符号信息。
- **QuaRot / SpinQuant**：分别使用预定义 Hadamard 旋转和学习正交旋转；本文在仿射变换框架内嵌入任务敏感的子空间校准。
- **FlatQuant**：使用可学习仿射变换+Kronecker 分解平衡表达能力与效率；本文在其基础上叠加一阶/二阶任务感知损失。
- **GPTQ / OBQ**：利用 Hessian 近似进行二阶优化，但面向权重而非激活；本文针对 VLM 激活的跨样本不稳定特性设计子空间方法。

## 局限性与未来方向
- **校准时间开销**：附录 A.1 显示 SubRot 比 FlatQuant 多出约 7 分钟的子空间统计时间（共 46:46 vs 39:43），对大规模模型可能成为瓶颈。
- **特征向量数 r 的选择**：论文固定 r 值，未探讨自适应选择策略及其对不同层/模型的影响。
- **仅针对旋转量化框架**：方法依赖 FlatQuant 的仿射变换框架，对其他量化范式（如分组量化、混合精度）的适配性未验证。

## 研究启发与可借鉴点
- **通道空间替代 token 空间**：利用固定维度的通道坐标实现跨样本稳定统计，可有效规避 VLM 中 token 数量/结构变化带来的不稳定问题，可迁移至其他多模态高效推理场景。
- **符号稳定方向的发现与利用**：在敏感子空间内识别符号一致的梯度方向并施加一阶引导，是一种将"误差方向塑形"与"误差幅度控制"分离的精细化校准思路。
- **泰勒展开的分级处理策略**：对一阶效应稳定方向用线性项引导，对不稳定方向用二阶项约束，这种分级处理可在不显著增加复杂度的前提下提升校准精度。
- **与团队方向结合机会**：可探索将 Fisher 子空间思想应用于多模态大模型的非对称量化或 KV-cache 压缩，结合在线校准进一步提升极低比特（W2A2）下的性能。

## 关键术语表
**Empirical Fisher Matrix（经验 Fisher 矩阵）**：基于校准集激活梯度外积的样本均值，作为自回归损失局部曲率的可计算正半定近似。
**Sensitive Subspace（敏感子空间）**：由 Fisher 矩阵前 r 个最大特征值对应的特征向量张成的通道维度子空间，集中了模型对任务损失最敏感的方向。
**Signed First-Order Effect（符号一阶效应）**：沿敏感子空间内特定方向施加扰动时，自回归损失在该方向上的变化符号在跨样本间保持一致。
**Rotation Quantization（旋转量化）**：通过正交或仿射变换混合通道维度以抑制激活异常值，再执行低比特量化的后训练技术。
**Cross-Sample Stability（跨样本稳定性）**：重要方向划分在不同校准样本间保持一致的能力，是 VLM 量化中避免过拟合校准集的关键属性。
