# 论文速读：WORLDPROBE: WHEN VIDEO WORLD MODELS FALL APART UNDER LONG-HORIZON SPATIAL EXPLORATION

## 一句话总结
本文提出 **WorldProbe**，一个基于目标条件多模态智能体的闭环诊断基准，用于系统评估视频世界模型在长达 180 秒、复杂空间探索任务下的长程表现；通过对 10 个 SOTA 模型的 1600+ rollouts 大规模评测，首次揭示当前模型在局部渲染稳定性上已取得明显进步，但在长程空间记忆保持与动态演化一致性上存在系统性崩溃。

## 研究问题与动机
1. **现有基准 horizon 过短且轨迹预定义**：主流评测多集中于数秒至数十秒的静态生成或固定相机轨迹，无法暴露模型在大幅度、长时段空间移动下的真实失效模式。
2. **缺乏对“世界持久性”的检验**：视频世界模型不应仅输出局部逼真帧，还需在重访、视角切换与连续探索时保持全局几何、纹理与语义的长期一致性，而现有指标多依赖相邻帧匹配或固定回环设计。
3. **长程交互控制链路工程缺失**：多数公开推理实现未暴露 chunk 间状态保留与在线动作注入接口，导致闭环探测难以稳定运行超过 30–60 秒。
4. **指标维度单一且偏向局部**：现有评测侧重视觉质量与控制跟随度，缺少对跨时间窗口的记忆保持（memory）与动态演化逻辑（evolution）的细粒度量化。

## 核心贡献（创新点）
1. **闭环代理探测协议**：将视频世界模型评测从“开环固定轨迹”升级为“目标条件智能体在线决策”的闭环协议，支持最高 180 秒的自适应空间探索。
2. **目标条件智能体与感知解耦设计**：以 Qwen3.6-27B 为核心构建智能体，并独立引入 SAM3.1 目标跟踪与 Depth-Anything-3 局部体素重建，解决长程探索中的目标 grounding 与近场碰撞回避，结构化推理使 agent 延迟降低 90% 以上。
3. **双视角四维评估体系**：提出从“局部指标退化”与“长程不一致性”两个互补视角出发，系统量化视觉质量、内容质量、长程记忆与演化保真度四个维度，弥补传统基准的盲点。
4. **千级 rollout 的大规模实证研究**：完成 10 个主流模型共 164 个测试用例、1600+ rollouts（约 800 分钟）的评测，首次系统性刻画“局部尚可、长程崩解”的普遍失效规律，并开源全部数据与代码。

## 方法详解
- **四类探测任务设计**：
  1. *Geometry Constrained Approach*：逼近部分可见目标并避开障碍，检验目标完整性与新揭示几何的一致性。
  2. *Open-Ended Traversal*：沿无界结构（道路、走廊）长距穿行，检验布局沿路径的连续保持。
  3. *Cross-View Inspection*：从不同视角观察同一局部，检验多视角一致性与新视角内容生成。
  4. *Successive Region Exploration*：连续重定向至不同外围区域，检验局部拼接与历史内容不丢失。
- **Agent 决策链路**：每步接收任务描述、近期帧窗口与辅助状态，从离散动作空间预测相机指令；动作经 model-specific driver 转换后注入下一 chunk 生成，输出帧更新时序上下文。
- **辅助感知模块**：
  - **SAM3.1 目标跟踪**：利用其记忆机制与文本条件追踪，在每个 chunk 后更新目标掩码；配合几何门控过滤帧间异常位移，防止目标跳跃。
  - **Depth-Anything-3 局部几何重建**：仅重构当前 chunk 尺度的粗糙体素，计算前向空闲距离；若 clearance ≤ 前一 chunk 前向位移，则强制覆盖 agent 的前进动作为转向，避免严重穿模。
- **评估指标构造**：
  - *局部退化*：视觉质量采用 MUSIQ、MANIQA、Q-Align 归一化后平均；内容质量由 VLM 独立评分几何有效性、物体完整性与场景丰富度（0–10）。同步记录 rollout 均值与时间斜率（Slope）。
  - *长程记忆*：使用 ViPE 逆推相机位姿序列，经最远点采样选出最多 5 个空间锚点（间距≥3m）；每个锚点选取视野重叠≥0.30、时间间隔≥8s 的有序帧序列，由 VLM 评分场景/布局/实体/纹理一致性。
  - *演化保真度*：将采样帧序列与控制摘要共同输入 VLM，评分实体演化、场景演化、物理合理性与动作-结果因果一致性四个子维度。

## 实验与结果
- **评测规模**：164 个测试用例，10 个 SOTA 模型（Matrix-Game 2.0/3.0, WorldPlay HY/Wan, LingBot-World v1/v2, SANA-WM, DreamX-World, AlayaWorld, ABot-World），累计 1600+ rollouts，总时长约 800 分钟，最大 horizon 180 秒，硬件消耗约 4 天（24×A100）。
- **局部质量退化**：所有模型均随时间下降，但新模型衰减速率显著更缓。LingBot-World v2 视觉均值最高（0.583），斜率仅 -1.02×10⁻³/s；ABot-World 最差（0.439，斜率 -5.48×10⁻³/s）。**内容质量退化始终强于视觉质量**（如 WorldPlay-Wan 内容斜率 -0.092 points/s），表明模型能在几何与语义严重漂移后仍维持表层渲染合理性。
- **长程记忆**：多数模型总分徘徊于 5 分或以下。AlayaWorld 最高（6.53），但仅能保留粗略布局，精细纹理与新视角一致性严重缺失；从非原始方向重访时，模型常生成完全不相干的场景替换原区域。
- **演化保真度**：各模型普遍偏低（3.0–5.0 区间），典型失效包括实体分裂/消失/重复、静态物体随相机平移、无动作触发的场景漂移、违反基本物理或因果规律的变化。DreamX-World 演化得分相对最优（5.17）。
- **Agent 有效性验证**：在无约束 DreamX rollout 中，代理可连续交互远超 180s 上限直至模型自身崩溃，证明评测框架本身不构成 horizon 瓶颈。

## 相关工作脉络
1. **WorldModelBench / WorldScore / iWorld-Bench**：侧重短时静态或简单交互生成质量评估，交互深度与轨迹复杂度远低于 WorldProbe 的闭环自适应控制，无法捕捉长程一致性失效。
2. **WorldMark / WBench / LoopNav**：WorldMark 使用 60s 预定义轨迹；WBench 平均仅 3.7 轮交互；LoopNav 虽达 1200 帧但遵循固定 Minecraft 环路，缺乏对生成几何的在线适应。WorldProbe 突破上述限制，支持任意轨迹与最高 180s 闭环探测。
3. **Genie / Genie 2 / Genie 3**：开创交互式世界模型范式，但评测聚焦短时交互与特定游戏环境，未系统评估真实连续视频场景的长程空间一致性与重访崩溃问题。
4. **VBench / VBench-2.0**：专注文本到视频生成的感知质量与条件忠实度，缺少对相机控制、跨视角记忆与动态演化逻辑的建模。
5. **记忆增强型世界模型（WorldDirector、Latent Spatial Memory 等）**：本文实证结果反向验证了这些方向的必要性——显式 3D 地图或持久化 latent memory
