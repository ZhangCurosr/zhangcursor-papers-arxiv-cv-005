# 论文速读：SEEING-WHAT-SHOULD-BE-HEARD: DIAGNOSING AND REPAIRING CROSS-MODAL SHORTCUTS IN OMNI-MODAL LLMS

## 一句话总结
本文发现并系统诊断了全能模态LLM中普遍存在的跨模态捷径问题——模型回答音频问题时过度依赖图像信息，并提出DMC-Repair方法，通过构建反事实网格并以指定模态重标标签进行训练，将图像诱导的答案效应比例降低59.9%，同时保持音频问答性能不变。

## 研究问题与动机
1. **核心问题**：全能模态LLM应使用问题明确指定的模态回答问题，但现有训练范式无法验证模型是否真正遵循该模态。
2. **捷径成因**：多模态训练数据中，图像和音频通常提供相同的证据支持同一答案，模型可通过任一模态获得正确答案而不受惩罚，从而形成跨模态捷径。
3. **现有诊断方法不足**：Media interventions等方法仅能暴露失败，无法定量分离每种模态对答案的因果贡献。
4. **现有修复方法不足**：
   - 解码方法（如AVCD、MAD）需要额外解码传递
   - 偏好优化方法（如ACPO、OmniDPO）需要构建偏好对
   - RL中的judge奖励反而可能放大对无关视觉信息的依赖（本文实验证实）

## 核心贡献（创新点）
1. **提出因子化模态诊断（Factorized Modality Diagnostic）**：通过经典2×2因子化实验设计独立隔离图像和音频对答案边距的因果效应，本质区别在于该方法能定量测量每种模态的贡献而非仅检测失败现象。
2. **揭示跨模态捷径的普遍性**：在HumanOmniV2和MiniCPM-o-2.6两种模型家族中，SFT和RL后训练各阶段均发现Shortcut Index接近0.5，表明模型对非指定模态的依赖程度与指定模态相当。
3. **提出DMC-Repair训练方法**：利用与诊断相同的反事实网格进行训练，按指定模态重标每个单元，只监督答案token，本质区别在于直接改变训练数据中"哪种输入预测标签"而非依赖额外奖励信号。
4. **验证跨模型泛化与零样本迁移**：修复效果在MiniCPM-o-2.6上同样显著，且零样本迁移到未见数据集（AVQA）和幻觉基准（AVHBench）均有效，且能保持通过后续RL训练。

## 方法详解
### 因子化模态诊断
- 对于音频问题q，选择两个共享问题但答案不同的真实样本o（own）和x（partner）
- 构建2×2网格，包含四种图像-音频组合：(i_o, a_o)、(i_o, a_x)、(i_x, a_o)、(i_x, a_x)
- 每个单元的答案边距：m_uv = log p(g|q, i_u, a_v) - log p(g'|q, i_u, a_v)
- 音频主效应：E_A = 1/2[(m_oo - m_ox) + (m_xo - m_xx)]
- 图像主效应：E_V = 1/2[(m_oo - m_xo) + (m_ox - m_xx)]
- **Shortcut Index**：SI = |E_V|/(|E_A| + |E_V|)，理想情况下音频问题应为0，视觉问题应为1

### DMC-Repair训练流程
1. **反事实网格构建**：配对共享问题但答案不同的样本，生成完整2×2网格（4个单元），其中两个为原始匹配单元，两个为反事实不匹配单元
2. **指定模态重标**：每个单元标签由提供指定模态的样本决定
   - 音频问题：标签 = 音频来源样本的答案
   - 视觉问题：标签 = 图像来源样本的答案
   - 多模态问题：仅保留原始两个单元
3. **答案token监督损失**：
   - 答案评分：s_θ(y|c) = (1/|y|) Σ log p_θ(y_t|c, <answer>, y_<t>)
   - Hinge损失：L(θ) = (1/|C|) Σ_c max(0, τ - [s_θ(y*(c)|c) - s_θ(ȳ(c)|c)])
   - 阈值τ=1.0，只对答案token进行监督，不约束生成的描述或推理文本

### 关键设计要点
- 训练数据无需合成或人工标注，仅依赖数据集已有的问题类型标注
- 模型必须从问题中学习何时使用哪种模态，而非习得固定的模态偏好
- 在完整网格中，每个答案出现两次（带不同非指定模态），非指定模态对标签无预测力

## 实验与结果
### 数据集
- **MUSIC-AVQA**：主要训练和诊断数据集，387个诊断族（193音频、80视觉、114音频-视觉）
- **AVQA**：零样本测试数据集，104个族，日常音视频QA
- **AVHBench**：幻觉基准，5,302个问题，包含音频幻觉、视频幻觉、音视频匹配三个任务
- **IntentBench**：通用全能推理能力评估，2,689个问题

### 评估基线
- HumanOmniV2（Qwen2.5-Omni + SFT + GRPO后的发布checkpoint）
- MiniCPM-o-2.6（不同架构的另一模型家族）
- 各类解码方法（AVCD、MAD）、偏好优化方法（ACPO、OmniDPO、MoD-DPO）

### 主要结果
| 指标 | SFT_clean | DMC-Repair (Full) | Δ |
|------|-----------|-------------------|-----|
| Audio问题SI | 0.549 | **0.187** | **-0.362** |
| Audio问题E_V | +1.05 | **+0.07** | -0.98 |
| Audio-Following (%) | 43.1 | **61.2** | **+18.1** |
| Matched-Cell Accuracy (%) | 61.5 | **67.3** | +5.8 |
| Visual问题SI（理想=1） | 0.713 | **0.872** | +0.159 |

**密封确认集结果**：SI降低**59.9%**，Audio-Following提高**13.7点**，所有7项预注册检验均通过。

**跨模型泛化**（MiniCPM-o-2.6）：SI降低约一半，零样本AVHBench准确率提升1.4点。

**零样本迁移**：
- AVQA数据集：图像效应降低62%，audio-following提高18点
- AVHBench音频幻觉任务：精度从61.9%提升至67.7%（+5.8），后续RL进一步提升至73.2%（+11.3）

## 相关工作脉络
1. **RL后训练方法**：HumanOmniV2、Video-R1等使用GRPO改进推理，但奖励仅检查答案正确性和格式，不验证模态使用情况；本文实验表明添加模态奖励的RL变体反而放大捷径。
2. **模态依赖诊断**：Media interventions（swap/mute/shift）和Modality shuffling方法可暴露失败，但无法量化每种模态对答案边距的独立效应；本文诊断互补性地提供了因果测量。
3. **反事实媒体训练**：Wen et al. (2026) 微调模型以检测音视频不一致并描述不匹配；Chen et al. (2026b) 在交换音频的片段上微调以回答指定类别；本文构建完整2×2网格使不匹配状态不携带答案信息。
4. **幻觉缓解偏好优化**：ACPO构建音频交换偏好对，OmniDPO构建音视频偏好对，MoD-DPO使用模态扰动偏好；这些方法均需要额外训练数据或偏好对，而DMC-Repair仅需原始数据。
5. **解码时方法**：AVCD、MAD等在推理时对比或重加权模态分支；DMC-Repair是训练时方法，无需额外解码开销。

## 局限性与未来方向
1. **适用范围限制**：当前重标规则仅适用于指定单一模态的问题；对于指定多模态的问题（如"图像和音频都重要"），反事实单元没有已知标签，仅保留原始两个单元，减少了训练信号。
2. **答案形式限制**：当前方法针对离散答案（如yes/no或乐器类别），未来可扩展到开放 ended答案。
3. **未探索的模态组合**：仅研究了音视频二元场景，尚未扩展到视频+音频+文本等多模态设定。
4. **推理阶段依赖**：虽然DMC-Repair在训练时修复了捷径，但在某些冲突单元上，最终checkpoint仍有约27%的情况跟随图像（而非音频）。

## 研究启发与可借鉴点
1. **因子化实验设计思维**：2×2因子化诊断框架可迁移到其他多模态依赖分析问题，如视频-文本、音频-文本等模态组合，用于量化每种模态的因果贡献。
2. **反事实数据构建策略**：通过配对相似问题样本并交换模态来构建训练数据，无需人工合成或标注，这一思路可用于解决其他模态混淆问题。
3. **答案token监督而非完整响应监督**：仅对答案token计算损失可避免对生成的推理文本施加目标，减少计算开销且不影响推理质量；这一策略在需要精确控制输出但允许自由推理的场景中具有借鉴价值。
4. **诊断与训练的统一框架**：同一反事实网格既用于诊断（测量SI）又用于训练（DMC-Repair），体现了"发现问题-解决问题"的闭环设计，可推广到其他研究场景。
5. **预注册确认协议**：使用密封确认集和预注册检验标准验证结果可靠性，避免对开发集的过拟合，这一严谨的评估实践值得借鉴。

## 关键术语表
**Cross-modal shortcut**：模型回答音频问题时，对图像的使用程度与音频相当甚至更高的现象，导致音频幻觉。

**Factorized Modality Diagnostic**：通过2×2因子化网格独立隔离图像和音频对答案边距因果贡献的诊断方法。

**Shortcut Index (SI)**：非指定模态主效应占总主效应的比例，SI=0表示完全不依赖非指定模态，SI=0.5表示两种模态贡献相等。

**DMC-Repair**：Designated-Modality Counterfactual Repair，通过反事实网格重标训练并监督答案token的训练修复方法。

**Counterfactual grid**：由两个共享问题但答案不同的样本的所有图像-音频组合构成的2×2训练单元集合。

**Audio-Following**：在图像和音频支持不同答案的冲突单元上，模型生成答案跟随音频的比例。

**Answer margin**：两个候选答案的对数概率之差，用于量化模型对某一答案的偏好程度。
