# 论文速读：SafeVantage: Vantage-Aware Memory for Reliable Embodied Decisions

## 一句话总结
提出 SafeVantage，一种面向部分可观测环境下具身决策的视点感知语义记忆与主动采集框架。该框架为每个类别主张保留支撑视图、相机位姿与目标几何估计，利用候选可见度预测与期望终端决策损失下降驱动视角选择，并通过几何一致性门控输出可靠的 YES/NO/ABSTAIN 选择性决策。

## 研究问题与动机
- **证据不可见性**：部分可观测环境下，仅凭语义分数无法揭示哪些视点支撑了特定主张，也无法指示应从何处采集额外证据。
- **信息压缩丢失溯源**：现有 VLMaps、ConceptGraphs 等方法将多视图观测压缩为单一语义节点或地图，丢失了视点头像、空间多样性与几何一致性，难以区分“证据不足”与“真实不存在”。
- **探索停止策略缺陷**：基于置信度的主动停止/求助策略在检测不可靠或搜索覆盖不全时易产生误判，缺乏显式证据状态来支撑后续视采与选择性拒绝。
- **决策风险未显式建模**：现有方法通常将覆盖率或召回率作为优化目标，未将假阳性、假阴性与旅行成本统一纳入决策损失，导致低预算下决策质量与效率难以兼顾。

## 核心贡献（创新点）
1. **视点感知语义记忆**：显式保留每个主张的支持视图、相机位姿与目标估计位置，将阳性支撑证据与搜索覆盖正交解耦。
2. **声明条件主动采集框架**：训练候选可见度预测模型，利用声称接地几何特征预估未访视点的目标可见
