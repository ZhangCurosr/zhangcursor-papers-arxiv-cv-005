# 论文速读：RA-CFGCache-From-Branch-Level-Criteria-to-Guided-Risk-Contro

## 一句话总结
本文针对 CFG 扩散模型推理中的免训练缓存加速问题，提出 RA-CFGCache 风险对齐缓存框架，通过显式建模跨分支误差几何与 timestep 依赖的传播权重，在完全保持原采样调度与引导规则不变的前提下，显著优化了生成保真度与推理延迟的权衡。

## 研究问题与动机
- **CFG 双分支高计算成本**：现代条件扩散推理需同时评估条件与非条件分支，现有免训练缓存仅将单分支复用逻辑简单平摊至两个分支，忽略二者误差在 CFG 组合后的交互效应。
- **分支–引导错配（Branch–guided mismatch）**：分支缓存误差的幅值无法直接等价于进入去噪更新的引导误差；后者还强烈依赖两分支误差的相对方向（余弦对齐度），且该对齐度随 timestep 剧烈变化。
- **局部–最终错配（Local–final mismatch）**：相同量级的局部引导误差在不同去噪步引入，经后续迭代传播后对最终隐空间状态的偏离影响差异显著，现有阈值控制未显式建模该时序传播效应。
- **方法与目标割裂**：主流 CFG 加速手段多通过修改引导尺度调度或稀疏化采样步来换取速度，而本文旨在保持原始 CFG 规则与采样步数严格不变，仅通过风险控制层实现无损加速。

## 核心贡献（创新点）
- 形式化刻画 CFG 缓存下的两类错配机制，推导出引导误差的精确几何分解式，并设计单步扰动实验定量验证局部误差到最终样本偏离的 timestep 依赖性。与已有工作仅关注单分支误差幅值的本质区别在于，本文首次将误差方向对齐与下游传播加权纳入统一的缓存控制理论框架。
- 提出 CFG 感知引导风险组合（CFG-aware Guided-Risk Composition），利用离线校准的跨分支对齐先验，将任意基础分支代理按 CFG 组合结构加权融合。与已有分支独立阈值方法的本质区别在于，代理信号不再孤立判读，而是按误差几何还原为真实的引导风险估计。
- 提出传播感知重缩放（Propagation-Aware Rescaling），用三参数幂律函数拟合单步扰动测得的传播增益曲线，对组合风险进行时序加权。与已有仅依赖当前步变化量的方法本质不同，该方法将局部风险映射为对最终输出的预期影响。
- 构建兼容 TeаCache/DiCache/MagCache 代理家族的即插即用在线阈值控制器，默认采用双分支联合复用策略。与需重新训练或修改网络结构的方法本质不同，本文框架完全零微调、零采样规则改动即可替换原有缓存控制逻辑。

## 方法详解
- **前置设定与 CFG 误差分解**：标准缓存以 $\tilde{p}_t$ 替换 $p_t$，误差 $\delta p_t = \tilde{p}_t - p_t$。CFG 下引导预测为 $p_t^{(s)} = u_t + s(c_t - u_t)$，缓存作用于独立分支后引导误差为 $\delta p_t = (1-s)\delta u_t + s\delta c_t$。其范数平方展开含交叉项 $2s(1-s)\|\delta u_t\|\|\delta c_t\|\rho_t$，其中 $\rho_t$ 为两分支误差余弦相似度；$s>1$ 时交叉项为负，正对齐引发抵消，负对齐引发放大。
- **CFG 感知引导风险组合**：不引入新误差估计器，直接接洽基线代理 $\hat{r}_u, \hat{r}_c$（MagCache 的幅值比累积、TeaCache 的时步特征相对变化、DiCache 的浅层探针相对变化）。离线在 100 条提示上统计各 $(t_a, t_b)$ 对的隐藏残差余弦相似度得到 $\bar{\rho}_{t_a,t_b}$，在线按公式 $(\hat{r}^{\mathrm{guided}})^2 = (1-s)^2\hat{r}_u^2 + s^2\hat{r}_c^2 + 2s(1-s)\bar{\rho}\hat{r}_u\hat{r}_c$ 合成引导风险。
- **传播感知重缩放**：通过单步预测扰动实验测量 $g_t = e_t^{\mathrm{final}} / e_t^{\mathrm{local}}$，发现其随执行步 index $k$ 呈系统性衰减，用幂律代理 $\hat{g}_k = \lambda((T-k)/T)^\alpha + \beta$ 最小二乘拟合。单步风险贡献修正为 $\Delta\hat{r} = \max(0, \hat{g}_b \hat{r}^{\mathrm{guided}})$。
- **在线阈值控制器与复用动作**：维护区间累积风险 $R$。若 $R + \Delta\hat{r} > \tau$ 触发刷新并重置锚点与 $R$；否则复用分支并累加 $R \gets R + \Delta\hat{r}$。默认动作选择**联合复用双分支**，在串行执行下跳过两路计算，在并行执行下消除
