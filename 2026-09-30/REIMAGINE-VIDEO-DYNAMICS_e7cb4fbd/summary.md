# 论文速读：REIMAGINE-VIDEO-DYNAMICS

## 一句话总结
本文提出 RVD 框架，通过自监督视频重建将视频动态（时序演化）与视觉上下文（外观与场景）显式解耦，学习一个紧凑的可编辑动力学 token；在此基础上构建语言引导的 token 编辑器，在同一框架内实现视频动态编辑、免训练重计时与外观可控重渲染。

## 研究问题与动机
- 现有视频编辑模型擅长修改外观（服装、背景、风格），但对视频动态（如跑变走、中途停下、物理结果改变）的控制能力有限，常因修改运动而破坏场景一致性。
- 核心瓶颈在于信息纠缠：主流方法在联合视频隐空间中操作，视觉上下文与动态表征混合，修改动态必然连带改变外观与身份编码，难以实现精准控制。
- 缺乏紧凑、独立且可直接编辑的动态显式表示，导致动态编辑难以泛化；同时真实场景中“同场景不同动态”的配对数据极度稀缺，制约监督学习。
- 作者希望将视频分解为互补的两部分（$\mathbf{V} = \mathbf{C} + \mathbf{D}$），使改变 $\mathbf{C}$ 只改外观而保留运动，改变 $\mathbf{D}$ 只改运动而保留场景，从而提供结构化、可复用的视频操控接口。

## 核心贡献（创新点）
1. **紧凑动力学 token 的自监督解耦学习**：通过“给定首帧与描述 + 动力学 token → 重建原视频”的自监督目标，迫使 token 仅保留运动演化信息；与现有方法的本质区别在于放弃联合隐空间编辑，转而在生成管线中显式隔离动态表征。
2. **语言引导的 token 空间编辑器**：结合 MLLM 语义记忆与动态编辑 Transformer，直接在压缩的时空 token 上完成源动态到目标动态的变换；区别于依赖姿态/轨迹等显式运动信号或隐式生成器控制的前作。
3. **可扩展的反事实视频对管道与两阶段训练策略**：利用 MLLM 规划 + 图像编辑 + 视频生成模型自动化构建 20K 反事实配对，并配合静态-真实伪对预训练，解决真实动态编辑配对数据稀缺与分布单一问题。
4. **统一的多功能视频操控框架**：基于同一解耦表征，无缝支持动态编辑、免训练重计时（时间轴重采样）与外观重渲染（固定 token 更换上下文），为后续视频世界模型提供可复用的动态控制接口。

## 方法详解
- **视频分解与学习假设**：将视频表示为 $\mathbf{V} = \mathbf{C} + \mathbf{D}$，$\mathbf{C}$ 由首帧 $I_0$ 与可选 caption 构成，$\mathbf{D}$ 为紧凑时空动力学 token；“+”表示生成性组合而非像素相加。
- **动力学编码器与瓶颈压缩**：冻结的 V-JEPA 2 ViT-L 编码器提取 $41 \times 16 \times 16 \times 1024$ 特征，经可学习瓶颈（时间打包、重叠 $3 \times 3$ stride-2 卷积、MLP）压缩至 $21 \times 8 \times 8 \times 128$，特征量缩减约 64 倍，过滤与动态无关的外观泄漏。
